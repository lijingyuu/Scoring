# 小程序页面清单（代码路径 ↔ 中文说明）

> 代码位置：`frontend/src/pages/`，页面注册表：`frontend/src/pages.json`
> 表格左列 = 代码里的真实路由路径（也是分享链接里的 path）；右列 = 这个页面是干什么的。
> 标 🏠 的是底部 tab 页；标 📤 的页面支持「发送给朋友 / 分享到朋友圈」。
> 分享直达的页面点「返回」会按层级自动上溯（如：记录页 → 赛程页 → 详情 → 首页），正常浏览不受影响。

## 一、Tab 主页面（共 2 个）

| 代码路径 | 中文说明 |
|---|---|
| `pages/index/index` 🏠📤 | **首页「赛事大厅」**。展示全部赛事卡片列表，可搜索、收藏；底部第一个 tab；点卡片进赛事详情，点「创建」进选择运动页 |
| `pages/mine/index` 🏠 | **「我的」页**。底部第二个 tab；个人资料、微信登录入口，以及「我的收藏 / 我创建的 / 已归档赛事」三个列表的入口 |

## 二、创建比赛流程（共 4 个）

| 代码路径 | 中文说明 |
|---|---|
| `pages/create/sport` | **选择运动类型页**。两个大按钮：羽毛球 / 排球，决定走哪条创建表单 |
| `pages/create/index` | **创建羽毛球比赛表单页**。配置赛制（淘汰/循环）、参赛人数、轮次规则、排名方式等；自定义排名会跳转排名设置页；创建成功后直接进入新赛事的详情页 |
| `pages/create/volleyball` | **创建排球比赛表单页**。配置排球规则（局数、每局分数、追分等）；创建成功后同样进入详情页 |
| `pages/ranking/custom` | **自定义排名规则设置页**。拖拽设置排名优先级；三处可进入（羽毛球创建、排球创建、小组赛页），设置结果通过本地存储传回原页面 |

## 三、赛事主链（共 9 个）

| 代码路径 | 中文说明 |
|---|---|
| `pages/tournament/detail` 📤 | **赛事详情页**。赛事名称/地点/规则/收藏数等信息；可收藏、裁判验证、归档；「赛程表」按钮进赛程页；团体赛多一个「查看队伍」按钮 |
| `pages/tournament/bracket` 📤 | **淘汰赛赛程页**（对阵图/签表）。展示淘汰赛对阵树；点击对局进入记分或记录页 |
| `pages/tournament/groups` 📤 | **小组赛赛程页**（小组循环 + 淘汰）。展示分组和每小组对阵；点击对局进入记分或记录页；还能进自定义排名设置 |
| `pages/tournament/teams` | **团体赛队伍列表页**。展示该赛事所有队伍；点队伍看成员，点编辑进队伍编辑 |
| `pages/tournament/team-members` | **队伍成员查看页**。只读查看某支队伍的成员名单 |
| `pages/tournament/team-edit` | **队伍编辑页**。修改队伍信息、增删成员 |
| `pages/tournament/mine-list` | **我的赛事列表页**。按 `type=favorites`（我的收藏）或 `type=created`（我创建的）展示两类列表 |
| `pages/tournament/archived` | **已归档赛事列表页**。从「我的」进入，点列表项可只读查看详情 |
| `pages/auth/pc-confirm` | **PC 扫码登录确认页**。用微信扫电脑上的二维码后，在此确认授权登录（确认/失败后回首页） |

## 四、执裁与记分（共 6 个）

| 代码路径 | 中文说明 |
|---|---|
| `pages/scoreboard/index` | **羽毛球个人赛记分板**（横屏）。实时记分操作；结算成功后跳转到该场的记录页 |
| `pages/tournament/team-match` | **团体赛单场对阵操作页**。一场团体对阵的信息与操作入口：进记分板、填名单、结算、看记录 |
| `pages/tournament/team-lineup` | **团体赛出场名单填写页**。填写某场团体对阵双方出场队员顺序 |
| `pages/tournament/team-relay` | **接力赛（人员流转追分）记分页**（横屏）。接力赛专用实时记分；结算后跳接力赛记录页 |
| `pages/volleyball/lineup` | **排球出场名单设置页**（竖屏）。设置双方上场 6 人及自由人；确认后进入排球记分板 |
| `pages/volleyball/scoreboard` | **排球记分板**（横屏）。排球实时记分；换边/重开/下一局会重定向回名单页，结算后跳排球记录页 |

## 五、赛后记录与签名（共 5 个）

| 代码路径 | 中文说明 |
|---|---|
| `pages/tournament/individual-record` 📤 | **羽毛球个人赛单场记录页**。展示该场详细比分与技术统计，可签名确认 |
| `pages/tournament/team-record` 📤 | **团体赛单场记录页**。展示该场团体对阵各局比分与结果，可签名确认 |
| `pages/tournament/relay-record` 📤 | **接力赛记录页**。展示接力赛分段得分过程与结果，可签名确认 |
| `pages/volleyball/record` 📤 | **排球比赛记录页**（竖屏）。展示排球各局比分与结果，可签名确认 |
| `pages/signature/index` | **手写签名板**（横屏）。裁判/记录员签字用；签完（或取消）通过事件通知打开它的那个记录页，然后返回 |

## 附：一句话记忆版

- **两个 tab**：`index` 首页大厅、`mine` 我的
- **创建三步**：`create/sport` 选运动 → `create/index` / `create/volleyball` 填表单 → （自定义排名 `ranking/custom`）
- **赛事三页**：`detail` 详情 → `bracket`（淘汰）/ `groups`（小组）赛程 → `teams` 队伍（`team-members` 看、`team-edit` 改）
- **记分五板**：羽毛球个人 `scoreboard/index`、团体 `team-match`、接力 `team-relay`、排球先 `volleyball/lineup` 后 `volleyball/scoreboard`
- **记录四页**：`individual-record` / `team-record` / `relay-record` / `volleyball/record`（都配签名板 `signature`）
- **两个列表**：`mine-list`（收藏/创建）、`archived`（归档）
- **一个特殊**：`auth/pc-confirm` PC 扫码登录
