从赛程生成到排名、出线和晋级，让赛事按确定规则推进

这里集中介绍循环赛、淘汰赛、小组 + 淘汰赛三类基础赛制，以及排名规则、轮空种子、出线判定和淘汰赛排签等特色能力。

赛制规则

01 循环赛 02 淘汰赛 03 小组 + 淘汰赛

一、循环赛

循环赛适合参赛单位不多、希望每个参赛方都有充分比赛机会的赛事。它的基本逻辑是：所有选手或队伍按照同一套规则互相交手，系统根据每场比赛的实际赛果排名，最终排名就是赛事结果。

在循环赛中，系统会根据参赛名单自动生成完整的循环赛程。单/双循环表示每两个参赛方交手一/两次。循环赛没有淘汰阶段，比赛打完后，系统直接依据排名规则排出名次。

小组/循环赛排名规则

排名规则是小组与循环赛的核心。系统提供各大球类标准的预设模板，同时支持将规则制定权交给主办方——可自由挑选相关排名判定指标，并按需设定判定优先级，完成自定义排名规则设置。

提供常用模板

官方排名规则： 内置羽毛球BWF（胜场 / 净胜局 / 净胜分 / 胜负关系）、排球FIVB（比赛积分 / 胜负局比值 / 得失分比值）、校园比赛（胜场/净胜局/得失分比）等标准、常用规则，不懂配置也能一键直接使用。

自定义排名规则设置

判定指标丰富： 涵盖胜场、比赛积分、净胜局、净胜分、得失分比、胜负关系等多种常用指标，按需自由组合。

优先级顺序自由： 自定义判定优先级。例：先看胜场 ➔ 相同看净胜局 ➔ 再相同看得失分比。系统会严格按你设定的顺序层层比对，精准算出排名。

二、淘汰赛

淘汰赛适合参赛者多、赛程时间有限、需要高效决出冠军的赛事。它的基本逻辑是：每一场比赛产生一个胜者，胜者进入下一轮，负者被淘汰，直到最后决赛产生冠军。

创建赛事时，系统会自动生成完整的可视化对阵晋级树。裁判在完成当场比赛比分结算后，系统会自动将胜者推进至下一轮对应的签位，无需主办方手动誊抄名单或重新编辑对阵，参赛者和观众也能实时查看整条晋级链路与赛程走向。

此外，系统支持分赛段规则设计，可将前期轮次设置快速推进的短局制，并在半决赛或决赛切换为偶然性更低的多局、长局制；可根据赛事需要一键添加季军赛。

轮空设置与种子体系

淘汰赛中，若参赛人数不是 4、8、16、32 这类能完美排表的数量，系统会通过设置轮空位补齐赛程位置。

如果部分选手需要按照平时成绩、历史排名或主办方安排设置种子序号，可以直接在名单前加上序号，例如“1 张三”“2 李四”。

系统会识别这些种子序号，并按照淘汰赛的排位规则安排签位。高种子选手会被分散到不同区域，且种子序号靠前则优先轮空，尽量避免强选手过早相遇。没有设置种子序号的选手随机填入剩余位置。

三、小组 + 淘汰赛

小组加淘汰赛是兼顾“参赛体验”与“决胜效率”的经典赛制。前半段通过小组循环赛保障各队有充分的比赛机会，后半段通过淘汰赛高效决出冠军，适合校园杯、院系赛、社团公开赛等中型赛事。

创建赛事时：除基本信息和名单录入外，主办方首先要设定分组数量与晋级淘汰赛总名额（例如分为 4 个小组、共8个淘汰赛名额）；其次，与循环赛相似地，主办方要为小组赛选择一套排名规则模板或做好自定义规则配置；最后，若有分赛段规则设计的要求，则要在网页端做好赛段划分以及每一赛段的规则配置。

小组赛阶段：系统根据名单（考虑种子序号）自动分组并生成组内赛程。随每场比赛结束，依据主办方设置的小组赛排名规则，同步更新各组排名表；

淘汰赛阶段：当组内名次锁定后，系统会按要求将晋级选手填入淘汰赛首轮，并生成完整的对阵晋级树，从而继续推进后续的淘汰赛赛程。

出线判定与淘汰赛排签

小组赛全部完赛后，系统会依据排名规则自动判定组内名次与出线名单。当排名规则无法区分名次、且该平局刚好跨越出线界限时，系统会拦截并要求主办方人工确认最终出线人选，其余不影响出线归属的平局均不影响赛程推进。

出线名单锁定后，系统进入淘汰赛首轮对阵预览阶段，提供标准交叉对阵（小组第一按组号顺序匹配小组第二，并回避同组选手）、随机排列（将出线选手随机排入签位且不回避同组选手）以及手动安排对阵三种排签方案。最终生成淘汰赛签表时，系统会进行校验，确保对阵选手必须与出线名单完全一致。
