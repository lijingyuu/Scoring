系统支持的赛事类型

赛事创建者负责赛事配置和赛程管理，裁判负责现场记分、阵容录入和结果确认。普通观赛者不是本文档的主要对象。

羽毛球个人赛

支持纯淘汰、小组赛加淘汰、循环赛。排名规则可选 BWF 标准或自定义指标，记分后自动更新签表和积分。

个人参赛 自定义排名 季军赛

羽毛球团体赛

支持苏迪曼杯五项和接力追分赛。排名模板按赛制隔离，阵容编排和父比赛结算串成完整闭环。

队伍参赛 阵容编排 独立排名模板

排球赛事

支持队伍录入、首发轮次、自由人、队长、换人、换边。排名规则独立维护并可选 FIVB 标准积分制。

FIVB 积分制 Phone / Pad 记分牌

完整赛事闭环

系统不是单纯的记分板，而是把赛事创建、赛程生成、现场操作、结果沉淀放在同一条链路上。

创建赛事选择运动、赛制、排名规则，录入选手或队伍，可选配置季军赛和赛段规则。
生成赛程自动生成淘汰签表、小组赛或循环赛，出线后支持三种排阵模式。
现场记分裁判按比赛类型进入对应记分或阵容页面。
自动结算保存比分、按自定义排名规则更新积分、推动淘汰晋级。
赛后归档战报签名封存，赛事归档后保留只读查看能力。

章节导航

文档按裁判和赛事创建者最常用的工作路径组织，可以直接跳到自己负责的比赛类型。

通用功能

登录、赛事列表、赛段规则配置、创建者与裁判权限、收藏和归档。

羽毛球个人赛

赛制选择、自定义排名规则、签表对阵、小组出线、季军赛、战报。

羽毛球团体赛

苏迪曼杯五项、接力追分、按赛制独立的排名模板、阵容编排、战报封存。

排球赛事

队伍录入、轮次填写、FIVB 排名模板、Phone/Pad 记分牌、比赛记录。
