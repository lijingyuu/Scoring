个人赛参赛单位：单人或双人组合

这里的“个人赛”指参赛单位直接参加抽签和比赛，不要求系统拆分管理组合内部成员。

单打

每行录入一名选手，系统把这一行作为一个参赛单位参与抽签、记分和晋级。

  • 一行一个选手
  • 可配合种子顺序生成赛程
  • 比赛结果直接归属于该选手

双打组合

两个选手可以写在同一行，中间用斜杠隔开，例如“张三 / 李四”。系统把这一行作为一个整体参赛。

  • 一行一组搭档
  • 组合名称直接显示在赛程和记分板中
  • 不额外拆分双打成员管理流程

创建页中的名单输入决定参赛单位：单打是一名选手，双打是一组用斜杠连接的搭档。

赛程生成：参赛单位进入比赛

赛制选择和赛程生成属于通用赛事能力，这里重点展示它们在羽毛球个人赛中的结果。

淘汰赛对阵

系统根据参赛单位生成完整签表。比赛结算后，胜者自动进入下一轮，不需要手工维护槽位。

  • 对阵双方直接显示为选手或双打组合
  • 未开始、进行中和已结束状态清晰区分
  • 结算结果推动后续轮次

参赛单位进入签表，胜者在比赛结算后自动进入下一轮。

记分板操作：完成现场比赛

记分板是羽毛球个人赛最核心的现场页面，裁判围绕比分、局分和比赛结算完成操作。

双方名称、当前比分、局分、发球方和比赛操作集中在同一页面。

比赛进行中的操作

  • 点击双方比分区域，为对应参赛单位加分
  • 使用“撤销”回退最近一次比分操作
  • 使用“换边”调整双方场地位置
  • 通过规则设置查看或调整局制、基础胜分和追分规则
  • 比赛结束后查看胜者、总比分、用时和各局比分

异常和确认提示

  • 决胜局达到阈值时提示是否交换场地
  • 当前局结束时提示换边并继续
  • 比赛锁定后通过“同步结算”提交最终结果
  • 退赛会直接结束当前比赛并记录结果

结果推进：积分排名和晋级

记分板完成结算后，个人赛根据当前赛制更新积分榜或推进淘汰赛。

排名规则：可选模板与自定义

羽毛球个人赛的排名规则不再是固定的"胜场→净胜局→净胜分"。创建赛事时可以选择预设模板，也可以自定义排名指标的先后顺序。

预设模板

  • BWF 标准规则：胜场 → 两人同分优先 H2H → 净胜局 → 净胜分 → H2H → 名字序
  • 常用模板一：胜场 → 净胜局 → 得失分比
  • 自定义：创建者从可用指标中按先后顺序自由组合

个人赛可选指标

  • 比赛胜负：胜场数、净胜场、胜负场比
  • 胜负局：胜局数、净胜局、胜负局比
  • 局内得失分：净胜分、得失分比
  • 胜负关系：两队直胜、多队小循环
排名模板按赛制隔离

羽毛球个人赛、苏杯五项团体赛、接力追分赛和排球赛事各自维护独立的排名模板库，不会跨类型复用。个人赛模板使用胜场、胜局、小分三层指标，不包含团体赛的"场内大分"和"场内局"。

排名指标决定积分表展示列

积分表的列（胜负、净胜局、得失分比等）会跟随当前排名规则动态变化，创建者设置的指标顺序直接体现在小组赛积分表中。

积分表与出线

展示分组、比赛状态和按排名模板定义的动态统计列。

全部小组赛完成且无未解决平局后，生成淘汰赛签表。

小组赛排名用于出线

排名指标按创建者选择的先后顺序逐级比较，直到分出先后。系统兜底规则在自定义指标无法区分时介入。

未解决平局可人工确认

如果出线边界存在自动排名无法判断的平局，系统提供"确认出线名单"入口，由创建者或裁判从并列候选人中手动选择出线者，而不是直接阻断流程。

生成淘汰赛：三种排阵模式

小组赛全部完成后，进入淘汰赛生成预览。系统提供三种出线者排阵方式：

标准交叉

小组第 1 名按组号升序、第 2 名按组号降序排列，自动避免同组首轮相遇。

随机排列

将所有出线者随机打乱后重新排入首轮对阵。

手动调整

进入槽位互换模式后，先后点击两个槽位即可互换双方位置，灵活微调首轮对阵。

季军赛

创建淘汰赛时可选开启季军赛。季军赛拥有独立的比赛规则配置（局制、基础胜分、追分机制和封顶分），与正赛规则互不影响。季军赛自动使用半决赛失利双方作为参赛方。

季军赛规则独立

季军赛的局制、胜分和追分规则可以在创建时单独设置，不与小组赛或淘汰赛正赛规则绑定。

战报展示

比赛结算后生成个人赛战报，集中呈现比分、对阵双方、各局详情和签名信息，作为赛后确认和留档依据。

  • 展示胜者和总比分
  • 展示每局具体比分
  • 保留选手签名和裁判签名区域
  • 支持签名后封存战报

赛后查看比赛比分、各局详情和签名信息。

战报封存需要权限验证

签名完成后，封存战报需要验证裁判密码或创建者权限，防止未授权修改。

记分结果由后端推动晋级

裁判提交比赛结果后，系统根据晋级链自动填入下一场，不依赖手工维护签表。

个人赛不拆分双打成员

双打组合以一行名单作为一个参赛单位，当前不单独维护组合内部成员的比赛状态。
