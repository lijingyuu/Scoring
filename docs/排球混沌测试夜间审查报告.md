# 排球混沌测试夜间审查报告（人类可读 · 追加式）

> 本文档是夜间自动混沌测试的**审查结论汇总**，由每轮值守 agent 追加写入，
> 供人工随时查看。产物明细在 `outputs/fuzz-volleyball/night/<日期>/`。

## 审查清单（每轮值守 agent 必查项）

1. **批次结果**：manifest 的 chunks 是否全部 exit=0；summary 的 critical/suspicious 是否为 0；matches 是否等于请求数。
2. **覆盖度**：summary.coverage 各项（reloads/sideSwitchKept/deepUndos/hostileRejected/decidingGame/capHits）是否非零且与局数直方图自洽；连续多轮覆盖度骤降要记录。
3. **统计离群**：回合/场、换人/场、撤销/场与历史均值（≈123.2/20.9/20.9）偏离超 2σ 的批次。
4. **非致命差异**：任何与常态不一致的信号——进度停滞段、stderr 新增内容、单场耗时离群、journal 里的结构异常（如阵型残缺、种子未按序落位）。
5. **跨局填写流**：lineup-flow journal 的 failures 必须为空；各局 rallies、reentries、serve 交替是否成立。
6. **后端赛制引擎**：journal 的 violations 必须为空；caseCount 是否随 scale 正常。
7. **产物卫生**：根目录合并视图是否指向最近完成批次；有无半截批次；`evaluation.jsonl` 是否连续。
8. **机器健康**：空闲内存是否骤降、vitest 是否有 timeout 字样。

**严重级别**：CRITICAL（不变式违反/断言失败，需立即按 SOP 修复）、
SUSPICIOUS（可复现的非常态，需登记并观察）、NOTE（记录在案的差异）。
