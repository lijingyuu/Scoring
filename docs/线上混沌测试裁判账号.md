## 使用规则

1. 混沌脚本引用位置：`scripts/test-live-badminton-chaos.mjs`（referees 数组）。
2. 测试赛事命名必须带 `混沌实测` 字样（如 `破冰混沌实测_xxxxxx`），测完删除。
3. 不要修改这些账号的昵称/密码；密码轮换时同步更新本文件与混沌脚本。
4. 若账号被锁/异常，直接重新注册同名账号即可（用户名唯一键幂等语义见 AuthServiceImpl）。
