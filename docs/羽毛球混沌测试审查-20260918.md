## 2. 静态审查发现的问题与当晚处置

### 2.1 已当晚修复（本次提交）

1. **冒烟落盘覆写夜间合并视图**（排球踩坑 #8 同款复发路径）：
   `badminton-fuzzer.test.js` 的批量冒烟此前落盘到默认 `outputs/fuzz-badminton/`，
   任何人在批后本地跑一次冒烟就会把合并视图 `fuzz-summary.json` 覆写成 5 场小样
   （审查当晚实际已发生一次）。
   **修复**：冒烟测试显式传 `outputDir = os.tmpdir()/fuzz-badminton-smoke`；
   编排器路径走 `FUZZ_SUMMARY_DIR`（优先级更高）不受影响。
2. **后端小组赛 gameScores 数据损坏**：无论谁胜局，`gameScores`/`scoreDisplay`
   恒写左方 21:15/21:18，导致 `GroupStandingEngine` 的得失分统计在约半数场次与
   胜者相反，三大依赖得失分差/比率的破平路径运行在垃圾数据上。
   **修复**：按 winnerId 与局分动态生成自洽的小局比分（每局 21:(12~19)，deuce 规则内合法）。
3. **tieUnresolved 硬编码 false**：引擎真实算出的"并列未破平"标记被丢弃。
   **修复**：透传 `Standing.isTieUnresolved()` 并新增自洽断言
   `TIE_UNRESOLVED_WITHOUT_TIE`（被标记者必须真的与别人并列同名次）。
4. **fs 落盘失败静默吞掉**（前端批量入口 catch noop）→ 已由子任务改为 console.error 留痕。

### 2.2 前端审计器当晚补强（badminton-fuzzer.js）
