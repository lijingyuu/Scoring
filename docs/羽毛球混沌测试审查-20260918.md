## 2. 静态审查发现的问题与当晚处置

### 2.1 已当晚修复（本次提交）

1. **冒烟落盘覆写夜间合并视图**（排球踩坑 #8 同款复发路径）：
   `badminton-fuzzer.test.js` 的批量冒烟此前落盘到默认 `outputs/fuzz-badminton/`，
   任何人在批后本地跑一次冒烟就会把合并视图 `fuzz-summary.json` 覆写成 5 场小样
   （审查当晚实际已发生一次）。
   **修复**：冒烟测试显式传 `outputDir = os.tmpdir()/fuzz-badminton-smoke`；
   编排器路径走 `FUZZ_SUMMARY_DIR`（优先级更高）不受影响。
2. **后端小组赛 gameScores 数据损坏**：无论谁胜局，`gameScores`/`scoreDisplay`
   恒写左方 21:15/21:18，导致 `GroupStandingEngine` 的得失分统计在约半数场次与
   胜者相反，三大依赖得失分差/比率的破平路径运行在垃圾数据上。
   **修复**：按 winnerId 与局分动态生成自洽的小局比分（每局 21:(12~19)，deuce 规则内合法）。
3. **tieUnresolved 硬编码 false**：引擎真实算出的"并列未破平"标记被丢弃。
   **修复**：透传 `Standing.isTieUnresolved()` 并新增自洽断言
   `TIE_UNRESOLVED_WITHOUT_TIE`（被标记者必须真的与别人并列同名次）。
4. **fs 落盘失败静默吞掉**（前端批量入口 catch noop）→ 已由子任务改为 console.error 留痕。

### 2.2 前端审计器当晚补强（badminton-fuzzer.js）

### 2.3 次日返工项（按优先级）

**P0-1（前端）通用记分板 fuzzer 驱动的是"状态机副本"而非真实代码。**
`badminton-fuzzer.js:72-499` 是 `pages/scoreboard/index.vue` 的手工转录（排球版
fuzzer 是 import 真实模块的）。已证实副本与真实代码存在语义分歧：
- 真实 `addScore(side)` 对非法侧别**无守卫**（index.vue:509-525，非法字符串会污染
  `serveSide`——调研 §7.5 已登记的真实缺陷），副本却加了守卫，探针恒绿、测不出该缺陷；
- 真实 `finishGame/retire` 有 `scheduleAutoSettlement()` 定时器、`uni.showModal`
  异步确认、`applySnapshot→applyRules` 归一化，副本全部省略 → 排球踩坑 #1/#2/#3/#4
  （微任务竞态/过渡窗口重入/僵尸 persistState/处理器重注册）在当前体系**结构性不可测**。
**候选路线**（需产品侧确认后实施）：a) 把 index.vue 记分逻辑提取为可 import 的
composable（推荐，排球 useScoreboard 即此模式）；b) 镜像排球 `lineup-flow-fuzzer.test.js`
用 fuzzer-env 驱动真实页面。改造完成前，该层只作"内核自洽性验证"看待（见 §4）。

**P0-2（后端）场景 3（团体提前终局）与场景 4（接力）为自证恒真断言。**
`winThreshold=(itemCount/2)+1` 是测试内复刻 `MatchSettlementService.java:415` 的公式；
接力链断言存在 `x.equals(x)` 永真式（测试:346-348）。两场景未触碰任何真实服务代码，
交付声明中"已覆盖团体赛提前终局/接力追分"在返工前**不成立**。
**返工方向**：改为调用真实 `MatchSettlementService`（pom 已含 Mockito，mapper 可 mock）与
`TeamMatchServiceImpl.validateRelayLineup/normalizeRelayItems`；或如实降级该两场景为"未覆盖"。

**P1-3（后端）确定性缺口**：`BracketEngine.java:88` 使用全局无种子 `Collections.shuffle`
→ 同 seed 无法重建同一张签表；`Violation` 不含 caseSeed，违规现场不可回放。
**P1-4（前端）3 条死断言**：`DECIDING_GAME_SIDE_SWITCH_NOT_PROMPTED`、

**P1-5（前端）镜像还原与 toOriginalSide/toOriginalGame 实现了但从未调用**——调研不变式 5
（换边/撤销 100% 镜像还原）在混沌主循环内零断言。
**P2**：批量 results[] 全量驻留（千场批建议只留异常场动作史）；接力终局审计缺
